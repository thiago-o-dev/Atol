# História

Separada em dois estágios:
- Acumulo de poder
- Corrida para retorna-lo

## Acumulo de poder
O narrador influencia o jogador a pegar poder dos templos, viajando pelas ilhas do Sankofa

## Corrida para retorna-lo
O narrador se revela como Leviatã, um devorador de mundos, que enganou você para destruir a barreira que protegia seu archipelago.

Agora o jogador pode escolher se entregar ao Leviatã, que é o final ruim, onde ele é rodeado pelo Leviatã e devorado, ou correr contra o tempo para retornar o poder aos templos, lentamente ficando mais fraco a cada devolução. Leviatã brinca, ele não tem pressa para ganhar, ele sabe que só precisa que uma pessoa esqueça dele.
